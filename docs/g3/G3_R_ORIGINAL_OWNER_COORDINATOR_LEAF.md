# Original-owner G3/O2 holds under one trainer snapshot lease

Status: **feature-private source prerequisite only**. The aggregate has no
linked Eshkol runtime gate, C2 claim, receipt, public SAVE, or replay.

`native/g3r_original_owner_coordinator_root.esk` loads one CLI3/TR3/T2/G3
registry through the accepted trainer-held G3 leaf, then the accepted held-O2
TR3 recheck and the coordinator extension. The six G3 source/test files are
byte-identical to reviewed leaf `ed3d6e4`; the branch does not merge its
unrelated sibling ancestry. The ordinary G3 eval-only constructor, ordinary
TR3 snapshot/load paths, and ordinary O2 busy rejection are unchanged.

`g3r-original-owner-begin!(trainer, generator)` preallocates its ledger and
both hold cells, then installs failure cleanup before calling the accepted G3
trainer-held begin. That begin enrolls the exact idle trainer snapshot lease,
requires its original train-mode M3T model and same-registry raw V256 tokenizer,
and takes the native G3/M3/A2 hold. The new O2 bridge obtains a fresh sealed
M3T fourteen-handle roster and gives it to the O2 held begin for the exact
optimizer pointer from that trainer record. The returned O2 pointer is rooted
immediately. The coordinator then repeats the held-safe TR3 parent/optimizer
count/absent-gradient check, Scheme generator/model/tokenizer checks, and
native G3 hold check before publishing only its private ledger.

On a recoverable begin failure the guard drains O2 first, then the accepted
G3 tail drains G3 and aborts the trainer lease. The explicit end follows the
same order. A nonzero O2 drain or any uncertain G3/lease cleanup fails stop
while the ledgers remain rooted. No C2 child, P1 clone, O2 state, result cell,
receipt, or file is published. A future coordinator successor must add a
compiled joint gate for normal and adverse native lifecycle cuts, exact held
O2 state adoption, partial C2 claim rollback cuts, reverse hold release, and zero
publication before any SAVE admission.

The C2 composition primitive now reconciles an attempted O2 claim before P1
rollback. It accepts only the exact preclaim LIVE state or this request's owner
token, and fails stop if either child's cleanup is uncertain. This is a source
repair to the detached C2 owner path; the original-owner coordinator still has
no held-safe P1 clone, held O2 adoption call, or original-control binding into
a C2 request. The existing TR3 snapshot composer calls ordinary O2 snapshot,
which rejects a busy held optimizer. The same-owner claim and receipt gates
therefore remain open.
