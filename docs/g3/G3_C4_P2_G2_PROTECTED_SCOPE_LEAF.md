# Private P2/G2 protected ownership scope candidate

This source-private dependency follows the [P2/G2 ownership admission leaf](G3_C4_P2_G2_ESHKOL_OWNERSHIP_ADMISSION_LEAF.md). It enrolls an exact native `(2,2)` call inside one `m3-call` region, reserves one pending `I1[2]` output, and captures the original call/model/generator/native/tokenizer core, child ledger, output shell/native, two-byte raw and sixteen-byte staging auxiliaries, and private one-byte raw and eight-byte ID carriers. The bytevector constructors establish complete header-plus-payload extents of `10/24/9/16` bytes. A separate source-private allocation-time anchor keeps the original identities independent of mutable record slots; the record checks both identity and declared length before later pointer use.

The scope has only a `before-prefix` phase. A test body must abort before leaving its call region, and the scope returns only `#t`. Explicit abort validates the original live links and child, then calls native abort. Native output-I1 and A2 lease checks reject before ownership mutation; the body can release a genuine lease and retry inside the same region. On success, abort scrubs the captured original bytevectors, tombstones the pending output, and clears the exact model/generator/call edges. A failed native abort preserves the Eshkol record and links. Native P2/G2 abort now preflights a staged token-frame transaction view before discarding that frame.

This is a protected ownership prerequisite, not the full prefix coordinator. It does not call the native carrier bridge, T1 raw decoder or prefix commit, and therefore makes no `3/1110` or successor-RNG rollback claim. The next gate must compose authentic sampled-ID staging, same-registry T1 decode and native prefix commit within this region, then prove both rollback phases. No second-token, EOS, terminal, public, provider or CLI behavior is added.

Static source closure and Clang syntax checks passed locally. Separate compiled feature-off and feature-on fixtures, including equal-length and paired identity substitutions, await the supported normal/repeat/sanitizer gate: this host is CachyOS, lacks `llvm-config-21` and the pinned Eshkol build. An older Eshkol compiler available elsewhere rejects current baseline `m3t` source syntax, so it cannot substitute for the supported gate.
