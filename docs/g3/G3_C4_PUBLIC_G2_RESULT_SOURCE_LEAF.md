# Public C4 P2/G2 result source candidate

This source-only candidate extends the accepted prezero public ticket and
private terminal origin. It does not establish compiled, runtime, or package
acceptance. The literal `diagnostic-c4-p2g2` creator profile, per-call ticket,
private origin, exact output shell/entry/native, surviving terminal anchor and
original policy are checked before every terminal accessor and native release.
An out-of-band private origin on a public-profile generator remains private.
Missing public or private roots cannot fall back to C2 while a C4 registry
entry exists. The G2 result leaf loads only in the installed aggregate, after
the byte-identical ticket dispatch and before the manual facade. The old P2/G1
adapter and its isolated fixture are unchanged.

Accessors take a real terminal native snapshot, including CPU i64 shape/device
admission, and compare a fresh snapshot before publication. IDs additionally
use the private logical I1 clone/copy/release route. Owned public tensors use
the accepted four-argument terminal result constructor for I1 `[1|2]` IDs
and I1 `[1]` length/cache; text is a detached bytevector and RNG has its own
native result owner. Result records retain only their own owner, count, words,
profile binding and phase. Published results can be released after source
output and generator close. A genuine held lease rejects output or result
release before mutation; staged result creation cleans up an unpublished
owner and retains the first error. Successful native release precedes fixed
root retirement.

The manual G3-G native owner receives exactly the accepted eight P2/G2 feature
flags plus its A2 terminal witness. Only the manual A2 object receives the
witness; generic and default tuples are unchanged. These source definitions
do not predict emitted object, local, undefined or exported symbol inventories.
The staged Eshkol fixture and source mutants cover missing origins, wrong
tuple/partial feature flags, snapshots, clones, detached owners, source-close
release and an out-of-band private origin. The fixture is **unrun**. Normal,
repeat, sanitizer, held-lease behavior, exact native object closure, emitted
zero tail, public package ABI and mathematical parity remain separate gates.
