# Private trained producer transcript candidate

This source-only candidate extends the accepted `01a584c6` budget-one
same-registry replay. The private entry restores the authentic CLI3 C2, saves
the exact C2 bytes and 288-byte companion, and observes the **decoded replay**
generator before its release. The prior captured P1 and uninterrupted G1
remain controls. The replayed generator supplies its 256 P1 logit bits, P1 and
G1 K/V cache bits, one sampled G1 ID, and P1/successor RNG words. The observed
G1 output length is one and its cache length is two.

The V1 6,292-byte image carries 14 ordered unique live parameter payloads,
copied through I2's checked native carrier borrow while the restored model is
retained. A local exact copy of the TR3 fixed roster checks each path/shape,
CPU f32 metadata,
byte count, and the token-embedding/head tie. It rejects a non-little-endian
host before copying native binary32 storage. An observer stages P1 only after
captured/replayed parity and G1 only after uninterrupted/replayed parity; a
final checksum and decoder round trip precede no-overwrite transcript
publication. A failure can leave an orphaned C2/companion pair.

`g3rt-decode!` checks the fixed header, both pair digests, companion budget,
record table, lengths, P1 RNG binding, and checksum before changing its sole
destination slot. A Python byte oracle exercises header, record, trace and
checksum mutation classes with unchanged destination. This does not yet prove
the compiled package, live bit capture, deterministic runtime modes, or fresh
process comparison. It remains a one-G1, context-two witness, not multi-token
or EOS continuation.
