# TR3-C private snapshot composer

This leaf composes one detached C2 training-state owner from an enrolled live
trainer at an admitted update boundary. It is private: the aggregate installs
no package facade and makes no public `trainer-state` or resume-equivalence
claim.

`tr3-c-trainer-state-internal` accepts the exact trainer shell and an empty
one-slot result cell. Its sole authority graph is the accepted trainer-owned
ten-slot snapshot parent. After lease entry and recheck it calls the genuine P1
`module-state-dict`, O2 `optimizer-state`, fresh D2 cursor, X1 inspection, and C2
compose seams. Each detached component is stored immediately in its promoted
authority cell.

C2 transfer is determined from the six-slot request after either return or
exception. Both component slots must be cleared and the output must identify an
exact live registered C2 owner whose P1 and O2 children are the cells' owners.
The composer then moves authority to the C2 cell. A wrapper's return value has
no authority.

Before C2 compose, the composer deep-copies and validates RNG, tokenizer,
current and epoch-start cursors, resolved X1 identity, and counters. Failure
clears and releases C2, O2, and P1 authority cells in that order, continues
after the first provider defect, and unlinks the exact parent through the lease
abort API. Success publishes the exact C2 shell to the promoted result cell,
clears the C2 cell, marks the parent dead, and invokes the assignment-only lease
finish tail. Neither path changes live model, optimizer, dataset, RNG, modes,
or counters.

The supported f31/LLVM 21 gate compiles the private aggregate at strict O0 and
runs normal composition, exact 42-tensor/control comparison, same-thread
reentry rejection, pre-compose component cleanup, post-transfer C2 cleanup,
source preservation, and retry. Public wiring, checkpoint serialization,
restore invocation, and interrupted/resumed equivalence remain later work.
