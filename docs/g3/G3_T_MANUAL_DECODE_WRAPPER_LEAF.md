[wrapper contract](G3_T_MANUAL_DECODE_WRAPPER_PROPOSAL.md) governs this leaf.

and both mask values; reviewed native preflight proves rank/shape `[1]` and
`[1,2]`, respectively. Native
decode tests remain separately in the same aggregate. Hosted integration and
independent source review are pending; only then may G3-M consume this seam.
