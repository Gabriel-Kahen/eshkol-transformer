# Public G2 prezero ticket source leaf

This isolated source candidate implements reviewed ticket design A
(`g3c4-public-g2-prezero-ticket-contract-20261009-a`) and its issuer/fixture
amendment B (`g3c4-public-g2-prezero-ticket-contract-20261009-b`). It is not
compiled or installed acceptance.

The public generator constructor accepts only literal `diagnostic-c4-p2g2`, budget two, and a byte EOS. It roots a creation-time profile row, anchor, and original-identity closure before native construction. The public generate callable alone issues a pending per-call ticket within its lexical secret scope. The fixed three-argument private route admits that ticket and invokes the origin-bearing terminal core with fixed prezero bind, verify and restore closures. It binds the exact output shell, entry, native handle and terminal roots before native zero. Successful native zero changes only preallocated ticket/row/anchor phase slots and returns the original shell. Out-of-band private origin-D calls do not issue public authority.

The public output adapter remains byte-identical to the accepted P2/G1 adapter. The isolated P2/G1 generation fixture contains test-local fail-stop definitions for the G2-only prefix and terminal core, because selected compiler `6803dbe2` rejects unresolved AOT calls even in an inactive branch. Those definitions do not load into the installed root; direct negative fixtures stage both failures. Four genuine P2/G2 private leaves are loaded in order in the candidate installed root before the adapter. Existing public names and arities are unchanged.

The source checker and mutation tests cover issuer scope, secret/current-ticket admission, prezero stage ordering, old-wrapper arities, load order, exact adapter identity, and fail-stop fixture closure. AOT compilation, direct-stub process exits, genuine first/second EOS, normal/repeat/sanitizer behavior, emitted outer-wrapper tail, native object/import/export closure, public result accessors and data-only continuation remain **unrun/pending**. No private origin marker or ticket alone authorizes a public result accessor.
