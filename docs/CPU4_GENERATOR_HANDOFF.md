# Closed CPU4 to public G2 handoff

This source-private leaf transfers the **same** trained or freshly restored C4
model from an accepted owned child/factory to the genuine public G2 generator.
It adds no native ABI, numerical/evaluation path, identity root, callback,
raw-pointer getter, general destructor or public facade. Factory23bc and its
positive64ea fixture remain separate unchanged leaves.

Private entries:

- `cpu4-owned-generator-handoff-internal!(child-token,generation-tokenizer,config,recovery-cell)`
- `cpu4-checkpoint-factory-generator-handoff-internal!(factory-ticket,generation-tokenizer,config,recovery-cell)`
- `cpu4-generator-handoff-retry-internal!(handoff-ticket)`

All three call the genuine checkpoint nonregional guard **first**. The scope is
fixed serial CPU-v1 with immutable trusted provider/codec/native/public dispatch
bindings; no arbitrary rebinding, callback, concurrent entry or general regional
reader admission follows. Pure preflight copying may allocate before ownership.
The fixed mutation tails contain no recursive/allocating publication helper.

The caller supplies a distinct explicit generation-tokenizer argument. Actual
`g3c4-baseline-tokenizer-entry` authenticates its original T1 authority. Training
T2 and caller D2 are retained independently and survive; their identities are
never silently aliased into T1. An explicitly reviewed T2/public-generation bridge
is a separate composition decision. The actual public profile parser/normalizer
rejects malformed/non-G2 config before detach. Sixteen accepted scalar/opaque
fields are copied into new list cells. Exact normalized policy words, seed or
original RNG entry, and native RNG word snapshot are retained and rechecked.
An RNG source remains that genuine public result authority; no seed replacement
or persisted continuation claim is made.

Before any destructive action, the recovery envelope, error cells, phase state,
result pair and registry cons exist and are globally rooted. Canonical readback
precedes recovery publication and the exact child's busy claim. Handlers precede
pending/busy publication. A pending handoff keeps that claim on error, blocking
old child/factory destruction while its exact recovery ticket remains usable.
There is no destructive rollback/cancel of trained data.

The phases are `training`, `detached`, `optimizer-retired`, `eval`,
`generator-owned`, then `adopted`. Exact O2 registry/ordered-handle/native
preflight and unlink planning precede TRAIN detach. The genuine trainer detach
releases the old binding; child[11] records it for retry. Each detached attempt
recomputes the unlink plan so unrelated optimizer insertions/removals between
serial calls cannot make an old predecessor/head splice destructive. The
existing **i32** `et_o2_private_candidate_retire_commit_v1(ptr,ptr)` with NULL
diagnostic destroys only its authenticated optimizer/moments. Native0 is followed
by fixed exact cons unlink, six O2 record invalidations and child optimizer-slot
clears before any further fallible operation. Model values, parameters, P1 handles
and graph memberships remain intact. A nonzero preflight result retains detached
custody and is classified from that direct O2 status, never a stale bridge cell.

Next `module-eval!` applies to the SAME model. Real
`g3c4-public-generator-create` owns its own rooted pending allocation transaction.
The exact returned generator shell is enrolled immediately. Any preadopt error
retains that shell and model for explicit retry; retry does not silently create a
replacement after successful construction. The leaf authenticates actual public
G2 profile membership and actual `g3c4-generator-entry-call-ready` immediately
before the typed base seam: profile[1] must be the exact registry entry,
entry[5] the original model entry, entry[6] the supplied genuine generation T1.
Caller-shaped full12 vectors cannot enter through these handoff entries.

The minimal base addition is a sixth lexical candidate operation,
`cpu4-candidate-adopt-public-g2-entry-internal!(candidate,entry)`. Its explicit
**source-private precondition** is that the closed leaf has just authenticated
public-G2 membership. The base independently validates the full12-slot idle
shape, policy/profile, exact same model crosslink and P1/I2 originals before
passing only entry[3] to the unchanged native adoption function. It cannot prove
public membership alone without adding a G2 dependency to standalone candidate
aggregates. No raw getter or callback is exposed. The original
`adopt(candidate,#f)` and existing nonfalse unsupported rejection are unchanged.
Old candidate/child source closures need no public-G2 helpers.

After native adoption0, only fixed writes and the preallocated model/generator
pair return remain. The child becomes a `dead` **ownership tombstone**: its
adopted model remains live, while O2/trainer/binding ownership is gone. Existing
later child/factory retirement is idempotent and cannot destroy that adopted
owner. The caller owns the returned model and public generator.
