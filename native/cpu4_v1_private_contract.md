# CPU4-v1 private source union

This noninstalled load root composes existing source, not a new runtime API or
installed selector. Composition base: `031aeeb5f41ab6c0a03d88b916c4360354894ea0`;
factory source is the exact eight-file `23bc7a7c` leaf.
`cpu4_v1_private_inputs.json` specifies ordered production TUs and per-TU defines.
`cpu4_v1_source_members.sha256` pins the static transitive Scheme inventory,
selected enclosing C TUs, conservative local headers/includes, and current IR
sanitizer transformation/proof. It is not a compiler depfile, symbol inventory,
import allowlist, or installed admission manifest.

The actual `g3g_manual_package_root.esk` supplies the full public generation
closure, original T1/I2/M3 helpers, and canonical C4 authority once. T2 remains
separate; T1 admission is never aliased. E3 contributes its specific leaves,
reusing the seven identical original boundary forms. The E3/checkpoint fixture
roots, copied E3 boundary and second I2 extension are excluded.

All TUs have candidate ON. The sole F32 integration is `m3_call_f32_integration.c`;
`g3t_transport.c` includes the sole M3 model/M3T transport; `m3_i64_integration.c`
includes I1; `e3_d2_native.c` includes D2. I2/O2 bridges are helper-only; no boxed
package bridge, `ET_M3T_PACKAGE_BUILD`, test feature, alternate registry, or native
provider copy is added. The six generation providers and CE/L3S/E3 metrics remain.
Loading legacy Scheme definitions does not enable native M3T model construction.

The actual `cpu4_checkpoint_factory_extension.esk` loads after checkpoint,
child custody and the existing C2 split reader/K2 leaves. Because the actual
`c2_public_extension.esk` also compiles inspect/SAVE branches, their real existing
leaves and native codec/reader/core/save/inspect providers are composed too.
`c2_public_extension.esk` installs `c2-policy-t2-entry-internal` once into the
original T2 policy projector; it creates no replacement T2 authority. K2's sole
TU has `ET_C2_CARRIER_FACTORIES`; the sole I2 helper bridge additionally has
`ET_C2_I2_MODEL_COPY`. Existing O2 reconstruction remains enabled. No C2/K2
whole root or boxed package bridge is loaded.

Factory create/retire and checkpoint snapshot/restore use the actual hosted
`region_current` query and require nonregional entry before any acquisition.
The factory retains exact reader/image/child recovery custody; its independently
reviewed source contract is in `docs/CPU4_CHECKPOINT_FACTORY.md`. The common root
adds no factory or checkpoint orchestration and no public names.

The lifecycle boundary is train/restore, E3 evaluate/drain/destroy (restoring
TRAIN), detach trainer/release binding while still TRAIN, `module-eval!` on that
same model, fresh generator, then native adopt. Moving persistently to EVAL before
detach fails the actual binding preflight. This root implements none of that
orchestration. Public G2 retains diagnostic C4/P2, budget two, explicit EOS 0..255,
and genuine typed result-RNG continuation; training's serialized RNG is not that
capability.

Only source guards may run before review/scheduling:
`python3 -B -m unittest -v tests.cpu4_v1_aggregate.test_source`.
The guards parse actual transitive source, reject duplicate top-level definitions
and enclosing native owners, and test candidate-OFF/M3T/identity mutations.
Native, AOT, IR, SAN, installed and end-to-end gates are NOT RUN.

caller must first be frozen, followed by compiler-observed closure/import
discovery and independent recipe review. Factory/guard source is composed, but
its actual FILE/native/AOT/SAN and NULL/nested-region witnesses are NOT RUN. Preserve the checksum-pinned
`tests/shared/prepare_eshkol_asan_ir.py` and
`tests/e3_private/check_asan_ir.py` proof together in any later SAN recipe.
