# Private C4 split native capture source leaf

This test-only source successor separates the supported Ubuntu 22.04/f31 native
observation from development-only Q0 mathematical comparison. It does not change
the accepted all-in-one runner, production lock, C4 math pins, frozen fixture, or
the D ROADMAP status. No guest build or native numerical result has been run for
this leaf.

An outer ROOT-reviewed gate must first pin the exact new clean C4 HEAD/tree,
the full 217-member source closure, the accepted E-b compiler result/physical
closure, f31 image digest, mount identities, tools, runtime libraries, candidate
lock, source/fixture paths, writable output, resource floor, and single-run
ownership. The `guest` route takes those exact source HEAD/tree values as
arguments and checks the actual clean Git revision, inherited accepted C4 base,
source hashes, Python 3.10, Ubuntu 22.04, external ordinary candidate lock,
selected tools/runtimes, and fixture before and after. The input source and pin
files must be read-only; output and `TMPDIR` must be fresh writable paths.

The guest builds the unchanged nine C11 sources in normal and ASan+UBSan+LSan
modes, retaining objects, archive, executable, symbol inventories, exact argv,
and bounded owned-child receipts. Normal first/repeat and sanitizer each run an
actual new child. The existing transcript helper requires genuine zero exit,
no stderr, finite streams, closed writers/session, and actual wait. The guest
requires identical raw streams across all three and writes canonical parsed
records plus a strict file inventory only after pre/post input checks pass.
On failure, partial diagnostics remain; absence of the final inventory denies
comparison.

After the outer gate has authenticated container shutdown, durable snapshot,
and immutable inventory, the `host` route reads that closed tree. It rechecks
the exact expected files and child receipts, reparses all three raw streams,
compares canonical bytes, and calls the existing frozen mathematical comparator
under the pinned Q0 Python 3.14.6/Torch 2.13.0+cpu environment. The host route
cannot itself prove Docker or durable physical closure; its input admission
belongs to the outer gate. It records a comparison only after pre/post source,
Q0, fixture, and guest-tree checks pass.

This leaf can support bounded private native numerical parity only. It does not
prove Eshkol AOT, emitted tail, null ABI, public symbols, terminal generation,
current-main integration, or full C4 acceptance.
