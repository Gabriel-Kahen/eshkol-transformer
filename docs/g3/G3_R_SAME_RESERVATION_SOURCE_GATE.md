# G3-R same-reservation source gate

This is a source-private, uncompiled candidate for the fixed diagnostic-C2
receipt-to-TR3 boundary. It composes the exact checked pair from `33b21bc8`
with the receipt and TR3 registries. Its sole entry is
`g3r-same-reservation-restore-internal!(row)`. The row is enrolled from an
exact live receipt, checked pair, idle trainer and registered raw-V256
tokenizer. The trainer's registered tuple supplies the resolved X1, D2
dataset, M3T model and O2 optimizer; callers cannot replace those components
through the bridge.

Under one receipt borrow, the gate authenticates the checked pair and copied
complete-image SHA, C2 controls, registered T1, canonical X1, immutable D2
cursor identity, fixed CPU-f32 model topology, O2 options, and private encoded
images of the 14 primary source tensors. It ends the receipt borrow once,
publishes `restoring` by assignment and passes only receipt slot 2's exact C2
owner to TR3. The receipt remains the C2 owner. Any borrow-end exception exits
134, including one raised after C2 consumed the borrow. A pair/candidate
recheck failure before TR3 returns the receipt to `live` only with an exact
live-C2 witness. A TR3 error exits 134 because current TR3 cleanup does not
expose a composed certainty witness.

The row retains the source bit images for a later exact restored-value and
gradient check. This gate neither releases the receipt nor publishes a model.
No compiled same-aggregate, fresh-process, fault-injection, sanitizer, typed
post-restore comparison, candidate-retirement, or replay evidence exists for
this source candidate. Until those gates pass it is not an admitted runtime or
G3-R continuation path. The closure manifest is a source inventory, not a
link or symbol proof.
The closure uses `internal/d2/lib/d2_semantic_core.esk`, the D2 root's actual
load target on this base. Source checks verify every listed path exists and
the reachable load and require chains from the checked-pair and TR3 roots are
present under the pinned include-path order.
