# G3-R private replayed P1/G1 candidate

This source-only candidate adds a generated-call transition from an authentic idle, manually committed P1 cache. `et_g3t_private_replayed_p1_g1_preflight_v1(void *)` reads the registered native generator without drawing or enrolling an output. `et_g3t_private_replayed_p1_g1_acquire_v1(void *)` repeats admission, pins the same 14 model parameters, checks their retained binding and A2 length-one state, then enters kind 2 with a private replay marker. The same-registry `(g3r-private-replayed-p1-g1! generator)` verifies its model and stored raw V256 T1 owner and uses the existing one-byte output, sampler, 21-role token frame and final publication. No detached logits, cache pointer, raw RNG words or history vector enters this ABI.

The marker is checked through output reserve/prepare/decode, frame begin/roles/prepare/commit, sample, final preflight, abort and finish. Fresh kind-2 preflight/acquire still reject a committed prefix. A P2 or length-two history, prior generated/manual append, terminal generated EOS, exhausted categorical RNG, busy/borrowed owner or changed model binding rejects before sampling. Prompt EOS alone does not end generation. Precommit abort preserves the generator's committed cache, last logits, ordered history and RNG; transient dead output tombstones may remain. After generated A2 commit, failure is fail-stop. The one emitted byte and successor RNG publish through the existing final path, and the full context bars another G1 request.

`tests/g3r/replayed_p1_g1_native_test.c` is a host-only synthetic state witness: pure preflight, full-context/borrow/pin/binding/draw-exhaustion negatives, ordinary generated-call rejection, marker-specific output enrollment, history predicate and abort/retry. It does **not** run G3-S sampling. `tests/g3r/replayed_p1_g1_same_process_test.esk` is an unrun fixture for the later immutable normal/repeat/sanitizer gate, comparing 256 logits, both A2 K/V rows, output ID/lengths and all four successor RNG words against uninterrupted generation. No Docker/compiled Eshkol gate, persisted C2 pair, public G2, broader context or full G3-R continuation is claimed.
