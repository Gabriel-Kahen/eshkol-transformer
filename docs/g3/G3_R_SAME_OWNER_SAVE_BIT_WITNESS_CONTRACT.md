## Fixed owner and parameter contract

The issuer must authenticate and root the **original** generator, M3T owner,
O2 optimizer, training-control capsule, T1 binding and D2 dataset. Capture
the seven-field training journal before trainer release; verify the genuine
unenrollment, retained graph, current and epoch cursor, tokenizer/config,
RNG, counters, and O2 update count. A direct enrolled step, evaluation,
restore, train, or release, reentry, or changed idle journal denies before a
SAVE grant. The held native reservation then pins that original graph, holds
the A2 cache read borrow and admits one O2 state issue. Its 18 scalar words
must come from that same held generator; the four G3-S RNG words and ordered
committed history must equal the pre/post native read. No seed reset or
independent generator clone substitutes for this check.

The M3T roster is exactly fourteen distinct primary live handles, each with
canonical row-major CPU-f32 shape and original P1 identity. The fifteenth
`token_embedding/weight` path is the **same handle and storage** as primary
10, `head/weight`; it is never a fifteenth payload or gradient slot.

## Bit and ownership proof obligations

Before detaching any snapshot, the native f32 witness must record, for every
primary, original child pointers, backing/shape/stride identities, value
bits, gradient bits, absent-gradient state, normalization-weight bits and
contribution count. This fixed profile requires an absent gradient whose
storage consists of positive-zero binary32 bits. Compare **raw bits**, so
signed zero and NaN payload changes cannot be hidden by numeric equality.
Recheck all fourteen witnesses under the original hold after P1 cloning,
after O2 state issue/claim, and before any future C2 publication. The P1
snapshot and O2 clone are detached baseline owners; they must compare to the
held originals but must never become the source of a supposed same-handle
observation. A second changed-value or changed-gradient read fails; it is not
repaired by replacing a baseline.

The existing source leaves retain authority in this order: training capsule
owns its journal and original roots; the native reservation owns G3/A2/O2
leases and fourteen f32 witness tokens; a one-use P1 bundle owns its detached
P1 state; the one-shot O2 state is reservation-owned until an authenticated
claim, then bundle-owned. The future C2 composer must authenticate every
bundle child and copied control before taking either detached state. Any
returned bundle is mutable and cannot be trusted by pointer equality alone.
Successful source capture ends the reservation only after final checks and
transfers detached owners exactly once. Failed capture retains the first
typed error, releases known detached children in reverse dependency order,
and drains the native hold. Uncertain cleanup retains all owner roots and
fails stop; it must not report a recoverable failure after an irreversible
write. The original graph, parameter/gradient bits, RNG, cursors, journal,
token count and caller outputs remain unchanged on every recoverable cut.

The contract witness must separately compare an uninterrupted run with a
same-process producer and fresh-process consumer: exact fourteen value and
gradient bit images, the tied alias, seven-field journal, token count, current
and epoch cursor, tokenizer/config identity, four G3-S RNG words, committed
history and terminal provenance. C2 complete-image digest and G3RCV1 pair
publication are later gates; these comparisons do not claim them.

## Static negative matrix and next gate

The static contract test checks the exact M3T roster/tie source, same-handle
value and gradient bits, detached baselines, journal/cursor/token/RNG drift,
and recoverable versus uncertain failure outcomes. Later implementation gates
must also reject wrong dtype/device, a different generator or O2 handle,
second O2 issue, forged/replayed bundle and partial-clone failure. Each cut
must deny before publication, preserve the first typed error and original
owners, and permit retry only after certain cleanup. Cleanup uncertainty
retains authority and fails stop.
