# Private P2/G2 Eshkol terminal-close source candidate

Status: private source and compiled-proof test candidate only. The
normal/repeat/sanitizer same-call gate, emitted tail and exact symbol review,
and public G2 admission remain pending. The accepted native terminal and logical I1 clone
APIs are prerequisites; this leaf does not change those native sources or the
nonterminal protected/prefix predecessors.

`g3c4-p2g2-terminal-close-private` authenticates an owned P2 input while the
generator is idle, creates an original one-entry pending output, and stages
genuine first-EOS-capable sampling and same-registry T1 decode. Non-EOS first
IDs commit the accepted prefix and sample/decode one genuine second frame.
The original record, allocation identities, pending ledger and phase are
checked before each native carrier and before terminal commit. Text and
pending-carrier scrubbing finish before the native zero boundary. The zero
branch only writes captured vectors, tombstones the drained call, and returns
the original output shell. The independently rooted terminal row remains
live after the call scope and records logical count and selected IDs, not a
fabricated precommit RNG value.

A separate fixed `g3c4-p2g2-terminal-close-origin-private` entry now stages
an independently rooted private production-origin row and anchor. They bind
the original generator and P2 input entries to the exact pending output
shell, entry, native owner and surviving terminal row/anchor. The final
prezero recheck authenticates these identities and selected count/IDs.
Rejected prezero calls restore both roots; a successful zero changes only
their preallocated phase slots before returning the same shell. Private
release authenticates the origin before native retirement, preserves it on
a held-lease rejection and tombstones retained owner references afterward.
The existing probed and two-argument close entries retain their behavior.
This private origin is not a public profile record and cannot authorize a
public G2 accessor or dispatch by itself. A distinct creation-time public
profile root and adapter remain separate prerequisites.

Separate private `m3-call` operations snapshot the terminal owner, create a
native logical I1 clone, copy its exact `[1]` or `[2]` words, and release
source or clone. The clone owns native storage independent of its source.
These private shells and copies are not public I1 tensors or G2 outputs.
The source-only checker enforces exact dependency closure, original carrier
comparisons, header extents, and a no-allocation/no-callback successful tail;
its mutation tests exercise those guards. The compiled runner is a proposed
future proof route and must be reviewed and admitted before execution.
The successor runner prepares a four prompt/mode matrix with genuine first
EOS and no-EOS cases and at least one distinct second EOS. A test-only native
witness captures actual selected IDs, 256 genuine P2/P3 logits, final RNG,
full K/V and model value/gradient/metadata. Separate native P3 and T4 forwards
provide the cache reference; a development-only Python Philox oracle checks
every emitted draw and branch. The native forwards reuse the production C4
math/kernel graph: they are a same-model parity reference, **not** an
independent mathematical full-model oracle. That separate C4 oracle remains
open. The source closure now includes the exact transitive test shim and
Philox reference bytes, with missing/drift rejection. The native-zero fence
covers the wrapped arena
allocators, malloc and exception-handler push through the outer `m3-call`
return. Prezero probes include original/equal-length/paired owner and ledger
drift, native terminal rejection and genuine I1/A2 lease release/retry.
The runner retains its exact normal/sanitizer archives, objects and AOT
executables on success as well as failure, plus ELF symbols, disassembly and
source/member hashes for later exact review. Collection alone does not prove the emitted
tail or public symbol closure.

The compiled proof must still run and establish these claims. Exhaustive
allocation/decode/native cuts, fail-stop at postzero fault cuts, emitted-code
nonallocation/nonthrow review, exact `'()` to C null ABI, and complete
private/public symbol closure need further source controls or compiled
observations. Failure to run that gate does not upgrade this source candidate
to accepted behavior.
The current Eshkol fixture uses initial Philox counters; Eshkol-level
singleton, carry, final and exhausted-counter cases are still open even
though native-only predecessors cover those boundaries.
